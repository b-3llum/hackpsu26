Chrome, Edge, Brave, and other Chromium browsers

Install Consent Receipts

About a minute. The Chrome Web Store listing is on its way; until then, install it from the file below.

Consent Receipts is installed in this browser. Connect it to your account to turn on AI summaries and Listen.
This browser can't load Chrome extensions. Open this page in Chrome, Edge, or Brave.

1. Download

A small zip file with the extension. Nothing runs until you load it in step 4.

Download the extension (.zip)

2. Unzip it

Double click the downloaded file. You get a folder named consent-receipts. Move it somewhere it will stay, like your Documents folder: Chrome loads the extension from that folder.

3. Open the extensions page and turn on Developer mode

Websites can't open this page for you. Copy the address, paste it into a new tab, then switch on Developer mode in the top right corner.

chrome://extensions

4. Load it

Click Load unpacked and choose the consent-receipts folder. Then click the puzzle piece icon in the toolbar and pin Consent Receipts.

That's it

The next time you click Agree or Accept on a site, a receipt appears in the extension. Create a free account and connect the extension to turn on AI summaries and Listen.

Updating: when a new version is out, download it again, replace the folder, and click the reload icon on Consent Receipts in the extensions page.
